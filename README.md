# Ana Luiza Rosa · Psicóloga

Site institucional da psicóloga Ana Luiza Rosa (CRP 09/20515), Goiânia – GO.

Site estático: tudo está no arquivo `index.html` (fotos embutidas). Não precisa de build.

## Publicar na Vercel
1. Importe este repositório em vercel.com → Add New → Project.
2. Framework Preset: **Other**. Deixe Build Command e Output Directory em branco.
3. Clique em Deploy.

Cada alteração enviada ao GitHub é publicada automaticamente.
